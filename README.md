# Vybe

Application mobile (iOS et Android) pour découvrir, suivre et garder en mémoire des concerts en France, avec le rap mis en avant.

Version en cours : **V1.0 (MVP)** — voir `docs/mvp.md`.

## Lancer le projet

```bash
npm install
npx expo start
```

Scanner le QR code avec l’appareil photo de l’iPhone (Expo Go), ou appuyer sur `a` pour l’émulateur Android.

## Stack

Expo + React Native (TypeScript), Expo Router, Supabase.
